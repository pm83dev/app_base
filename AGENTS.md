Scopo del progetto: Sviluppo di un'applicazione di showroom con API backend e frontend.

Stack e versioni:
- .NET 10.0
- PostgreSQL
- ASP.NET Core
- Angular

Comandi build/run:
- `dotnet build backend/backend.Api/backend.Api.csproj`
- `dotnet run backend/backend.Api/backend.Api.csproj`
- `npm run build` per il frontend

Struttura cartelle principale:
- `backend`: API backend
- `frontend`: Frontend Angular

Note operative:
- Assicurarsi che il backend e il frontend siano sincronizzati correttamente.
- Verificare la configurazione di database e pacchetti.
