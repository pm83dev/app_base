Scopo del progetto: Demo Showroom backend

Stack e versioni reali:
- .NET Core 3.1
- Node.js 14.17.0

Comandi build/run con path esatti:
- Build: dotnet build C:\DEV\DEMO_SHOWROOM\app_base\backend\backend.Api.csproj
- Run: dotnet run --project C:\DEV\DEMO_SHOWROOM\app_base\backend\backend.Api.csproj

Struttura cartelle principale:
- backend.Api: Contiene i controller e le configurazioni dell'API.
- backend.EventManager: Gestisce gli eventi e le operazioni di dominio.

Note operative per agente AI:
- Assicurati di avere .NET Core 3.1 installato.
- Usa 'dotnet build' per compilare il progetto.
